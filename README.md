# Dogfight

브라우저에서 바로 실행되는 정적 HTML 게임이에요. 빌드나 서버가 필요 없어요.

`index.html` — Dogfight: 자동 발사 종스크롤 슈팅, 보스전, 스킨 상점

## 2인 협동 (파티 코드)

1. 한 명이 시작 화면에서 **함께하기 → 방 만들기**를 누르면 6자리 파티 코드가 나와요.
2. 친구가 **함께하기 → 코드 입력 → 참가**를 누르면 연결돼요.
3. 방장이 **출격!**을 누르면 함께 시작해요. 체력과 궁극기는 각자, 점수는 공유해요.

WebRTC(PeerJS 공개 시그널링 서버)로 브라우저끼리 직접 연결하는 방식이라 별도 서버가 없어요.
방장 브라우저가 게임을 계산하고 친구 화면에 실시간으로 보내 줘요. 방장 탭이 백그라운드로 가면 게임이 멈춰요.

## 배포 (Vercel)

저장소를 Import 하면 설정 없이 그대로 배포돼요. Framework Preset 은 **Other**, Build Command 와 Output Directory 는 비워 두세요.

## 저장 데이터

최고 점수, 포인트, 보유 스킨은 브라우저 `localStorage` 에 저장돼요(기기마다 따로).
